# Campus Events companion

Read the [Module 2 guide](../README.md) for setup, code explanations, exercises, and limits.

From this directory with Node.js 24.x:

```powershell
npm ci --include=dev
npm run dev
```

Open the URL printed by Vite. `npm run check` runs helper tests and a production build. All changes are held in React memory and reset on refresh. No database or credentials are required.
